# 社区两项核心价值：计划同路人与关注关系

日期：2026-11-10
状态：产品设计补充。公开图文、关注流和主动计划摘要推荐已有首批本地实现；创作者认证与完整关系机制待做，见[实施范围](COMMUNITY-IMPLEMENTATION.md)。
关联：[社区 PRD v0.3](COMMUNITY-PRD.md)、[机制研究](COMMUNITY-MECHANISMS-RESEARCH.md)

## 1. 用户本轮明确的方向

1. 个性化训练计划仍会在一部分用户之间高度相似，可以用计划相似程度发现正在做相近事情的“同路人”。
2. 关注是社区必要能力。用户希望表达的运动理念是：运动为了更好的生活方式、健康、活力与幸福生活，让不同身体条件、目标和阶段的人都能有自己的位置。
3. 社区可以成长出被认同、能给予精神鼓励与方向感的创作者。社区既要帮助人结识身边的同伴，也要让人持续关注自己认同的人。

建议理念表达：**让运动成为健康、活力与幸福生活的日常。** “生命强度”在这里表达对生活的投入与体验，不等于更高训练强度、更多重量或平台可承诺的寿命结果。

这两项分别支持同伴关系与内容关注，再与固定小圈、约练和共同回顾结合。等级、火花和折扣帮助表达这些关系，不取代关系本身。

## 2. 同路人：计划相似是有价值的发现信号

### 2.1 能推断什么、不能推断什么

可以说：“你们正在练相近的内容，有共同话题，也可能适合交流或一起练。”

不能直接说：“你们身体状况相同，适合完全相同的剂量。”不同人的时间、器械、偏好、经验或限制都可能产生相似计划；相似身体条件也可能因为兴趣不同选择不同运动。推荐关系不作为身体诊断，更不代表对方适合照抄计划。

个性化不要求每个人的计划都不同到无法比较。可以在相同动作模式与阶段目标上相似，同时在具体动作、重量、组次和节奏上各有调整。共同点能帮助认识人，差异仍由各自训练安排承接。

### 2.2 两个问题分开判断

| 问题 | 用什么判断 | 产生什么结果 |
|---|---|---|
| 我们是不是在走相近的路 | 当前有效计划的结构、目标、阶段、频率与项目 | 同路候选、共同话题、推荐理由 |
| 我们是否适合实际一起练 | 自愿填写的时间、片区、场地、互动方式和约练意愿 | 固定练友/线下约练候选 |

不同城市的两个人可以是很好的线上同路人；同一健身房的人也不必采用同样计划。不能让“距离近”取代同路程度，也不能让计划相似自动授予查看位置或发消息的权限。

### 2.3 优先比较哪些信息

| 特征 | 建议用法 | 注意点 |
|---|---|---|
| 目标与活动项目 | 用户主动选择的力量入门、跑步、灵活性、日常活动等 | 不从疾病、体重或疼痛文本自动推导社交标签 |
| 动作结构 | 推/拉/蹲/髋伸/核心等模式组合、计划的重点 | 同一模式的替代动作也能形成共同点，不能只按名称逐字匹配 |
| 训练阶段 | 用户已知的入门/进阶，以及当前计划的训练侧重点 | 课程第几周不自动等于人的能力阶段 |
| 频率与时长 | 每周安排、单次时长的大致相近程度 | 目标时长是安排，不冒充实际执行或体能 |
| 场景与器械 | 居家/场馆、徒手/哑铃等可比较条件 | 既帮助交流也便于约练，但器械不决定一个人的身份高低 |
| 执行与偏好 | 当前计划是否仍在用；用户主动反馈是否想交流同类内容 | 计划推荐与真正执行分开，不能拿未执行计划声称“你们一直一起练” |
| 时间与地点 | 仅在实际约练排序阶段加入，且用户主动选择 | 不读取或公开精确行踪 |

首版优先做可解释的特征比较：动作标识、动作模式、项目与用户选择的目标。动作模式分布可以归一化，防止动作多的计划天然得到更高分；共享的通用热身、放松等内容降低区分作用。未报数的推定次数不当作相似体能的实测证据。

先产生相关候选，再按双方交流意愿、时段、片区等排序。缺失字段当未知，不能当“相同”；无法可靠比较时降低置信、减少推荐理由，不凑出完整百分比。不在这一版拍定 80% 就是同路人或一套固定权重。

这是将可解释的内容特征比较用于人的发现的设计提案。Google 的[内容推荐说明](https://developers.google.com/machine-learning/recommendation/content-based/basics)支持用特征表达相似性的基本思路，其[局限说明](https://developers.google.com/machine-learning/recommendation/content-based/summary?hl=en)也强调特征设计的限制；它没有证明计划相似的人更容易成为朋友，这一步需要本项目验证。

### 2.4 推荐理由与反例

| 情形 | 应怎样处理 |
|---|---|
| 两人都是居家哑铃入门，每周三次，主要动作模式接近 | 可推荐“都在做居家哑铃入门，训练节奏也接近” |
| 一个用哑铃深蹲，一个用适配的其他蹲类动作 | 保留动作模式上的共同点，不要求动作名完全一致 |
| 都有深蹲，但一个准备比赛、一个只想日常活动 | 不能仅因一个重合动作判成高度同路，需看目标与整体结构 |
| 都使用同一个平台默认课程模板 | 先检查是否只是模板共性，不能因此给所有人高置信推荐 |
| 用户只有一次自动生成的计划、尚无实际训练 | 可以给“计划方向接近”的弱推荐，不展示“训练习惯相同” |
| 计划因不适或个人安排变化 | 用新有效计划更新推荐，保留已有朋友；不强制拆圈 |
| 两人的计划相似，但其中一人不愿参加约练 | 可以关注其公开内容；不能替他开启招呼或线下匹配 |

### 2.5 隐私与更新

- 以用户同意使用计划摘要做同路推荐为前提，与公开原始训练记录分别控制。关闭后停止新的计划匹配和相关推荐缓存使用。
- 生成独立的社交推荐摘要，只保留需要的运动结构与自愿标签；不把原始健康问卷、病史、疼痛记录、限制原因或私人教练聊天直接送入社交推荐。
- 不在推荐理由中写“你们都膝痛”“你们有同样疾病”。用户主动公开康复经历也不等于允许平台向他人推断病史或给他人的病症贴标签。
- 低强度、动作排除等结构也可能让人联想到身体情况，因此理由只选用户允许公开的概化共同点；人数过少或明显具有敏感指向时不显示精确群体规模和归因。
- 推荐以当前有效计划为主，保留来源、版本和更新时间。历史用于辅助，不用已弃用计划持续贴标签。
- 换计划更新新候选；已关注的人、已有朋友和加入的小圈不自动删除。用户可以反馈“不像我”“只是计划类似”“不想认识此类人”并纠正推荐。

### 2.6 现有代码能支持什么

已核对现有源码：

- `src/core.ts` 中的 WorkoutSession 有 goal、environment、plannedDurationMinutes、exercises、prescription 等；动作目录有 movementPattern、equipmentIds、difficulty 等，可作为结构化比较基础。
- `src/program.ts` 的多周课程目前主要是周/场模板，不保证每个未来场次都有已生成的动作清单。部分场次复用同一需求文本，不能仅凭标题、周次或 input 相同生成“高度相似”的结论。
- 用户经验与能力存在部分结构，但数据可能缺失，且能力估计不应直接作为公开健康档案。

首版用实际已生成且仍有效的计划、可比的动作结构和明确选择的标签。未生成未来计划时不为凑推荐制造训练会话；没有计划则用本人选择的运动项目/目标做冷启动，并明确“按你选择的方向推荐”。当前系统未覆盖的运动类型不编造计划相似度。

## 3. 关注：从第一天开始的独立关系

| 关系 | 含义 | 是否需互相确认 | 能否直接私聊 |
|---|---|---|---|
| 关注 | 我愿意持续看到这个人的公开内容 | 公开档案单向；私密档案需批准 | 否 |
| 同路推荐 | 系统认为当前计划/方向有可解释的共同点 | 进入发现需相应同意，推荐不自动建立关系 | 否 |
| 练友 | 双方同意持续交流 | 是 | 受既有规则和屏蔽状态约束 |
| 圈成员 | 我加入一个共同参与的空间 | 按圈规则加入/批准 | 不自动获得成员私信权限 |

关注从第一天开放，不绑定等级、连续打卡或购物。对创作者的欣赏也不要求计划相似；一位偏好散步的人完全可以关注讲述运动生活的跑者。

“关注”流优先完整呈现已关注者有权限发布的内容，默认按时间呈现，可选推荐排序；外部推荐单独标识，不偷偷让关注列表失去作用。置顶与合集可帮助认识创作者，但关注不默认开启每帖通知。

用户可取消关注、移除粉丝、屏蔽、举报和关闭通知。取消关注不自动解除练友；屏蔽则切断对应联系与推荐。私密内容需要每次读取和媒体访问都校验权限，不能靠“关注过一次”永久获得。

社区结构建议：**关注 / 同路人 / 发现**。同路人以相近计划和阶段为中心；发现在主题、创作者与同城活动之间展开，容纳项目不同但理念相通的人。同城约练保留在发现内，不将整个社区都做成附近找人。

## 4. 创作者与 KOL：可以因生活理念获得认同

### 4.1 谁值得被关注

| 创作者方向 | 可以提供的价值 |
|---|---|
| 普通人的日常运动 | 忙碌工作与家庭中如何保留活动，让新用户觉得自己也有位置 |
| 长期陪伴与重新开始 | 中断、低落或目标变化时怎样回到适合自己的节奏 |
| 走路、户外、跑步、力量等不同项目 | 展示不同运动生活，让用户选择自己愿意持续的方式 |
| 自主分享的恢复经历 | 分享个人历程与生活体验，明确个人经验的范围 |
| 有真实专业资质的创作者 | 在其资质和内容范围内提供知识，认证、合作与利益关系透明 |
| 小圈组织与共同活动 | 能欢迎新人、主持交流、组织可靠活动的本地连接者 |

不是所有创作者都要有极高等级、显著身材变化或竞技成绩。等级记录参与；受关注是他人选择；专业资质另行核实。三者不互相替代。KOL 是可能逐步形成的角色，不预先承诺每个圈一定出现精神领袖，也不把“粉丝多”自动等同内容可信。

### 4.2 内容与分发

用户进一步确认：关注可以来自认同一种生活方式、被鼓舞、获得想要的信息、向往某种生活，也可以来自审美与单纯喜欢看。平台应承认这些动机各自成立，不要求每个关注都对应相同训练计划或明确学习目标。

**好看的照片、身材与运动成果展示、训练经历、生活感受，都可以独立成为有价值的内容。** 发布照片不必附教学、训练数据或前后对比；分享经历不必总结成方法论。平台鼓励用户真实表达，通过持续看到喜欢的人与内容形成关系。

- 让生活照片、身材与运动成果、训练经验、恢复、心情、日常活动、共同出游和运动带来的生活变化都有合适主题。
- 保留原创主页、公开动态、系列合集、持续关注与留言交流；普通人也能得到第一批真实回应。
- 发现推荐综合内容相关性、长期正反馈、用户收藏/回访、原创与可信程度，不单看粉丝数、观看时长或刺激性前后对比。
- 推荐中保留新创作者和小体量内容的探索机会；内容流不能挤掉固定圈与练友关系入口。不在本稿凭空规定流量比例。
- 创作者可组织主题活动或申请圈子角色；平台支持申请、审核与交接，不因等级或粉丝数自动给管理权。
- 商业合作明确标识，相关资质可核实；不出售向粉丝强制发私信的能力，不把购物量作为社区地位。

### 4.3 平台要传达的文化

建议把用户理念写成社区准则：

1. 运动服务于生活，用户可以拥有不同的目标与节奏。
2. 尊重散步、基础活动、恢复和重新开始等不同形式的投入，不只赞赏高强度与竞技成绩。
3. 不用身材、体重、年龄、残障或伤病羞辱别人，不用“没自律就是失败者”制造认同。
4. 鼓励有意义的陪伴和真实经历；展示成果时保留过程，不用个例保证所有人效果。
5. 个人经验与专业建议分清；社区关系不替代个体训练安排或适用的专业指导。

[WHO 的公开说明](https://www.who.int/news/item/25-11-2020-every-move-counts-towards-better-health-says-who)支持不同年龄与能力的人都应有适合自己的活动机会。本文据此强调社区包容性，不提供具体康复处方，也不宣称当前 TrainMind 已具备所有疾病康复服务。

### 4.4 愿景如何落实到当前范围

当前产品以结构化训练场次为主，不能把“至少有两次力量训练”变成所有运动人群的永久社交门票。

后续通用的有效运动日需支持不同项目自己的记录方式，例如步行/跑步/灵活性活动的相应记录。来源与可信度独立保留，不用组记录硬套所有运动；平台外自述先作为内容展示，不能伪装成已核验运动。

在多运动记录尚未落地前：浏览、关注、分享、圈内参与对不同目标用户开放；陌生招呼与约练按当前支持模式执行并清楚说明限制。逐步增加被支持的有效活动类型，再统一扩展资格，不编造已具备的能力。康复需求是包容对象之一，不自动变成一键生成医疗康复方案。

## 5. 首版交付优先级

- **同路发现**：可解释的计划结构基线、主动标签冷启动、推荐纠正和退出，不先做复杂黑箱模型。
- **关注**：关注/取消、公开/私密档案、关注流、通知与屏蔽，从第一天可用。
- **关系**：固定圈、练友与共同周目标继续为核心，不能只有推荐人列表。
- **创作者**：能持续发布与被关注，主题内容和运营示范；不先上线付费 KOL 等级与流量交易。
- **包容性**：内容文化与基础参与先落实；多运动事件口径与专业服务按实际能力逐步扩展。

## 6. 怎么知道这两项价值成立

| 环节 | 要观察什么 |
|---|---|
| 计划相似是否帮助关系形成 | 与仅按用户项目/阶段标签推荐比较，同一个人是否被重复回应、是否自愿成为练友 |
| 模板是否造成假相似 | 控制默认计划、动作库覆盖和推荐曝光位置，检查用户认为“像我”的比例与错误案例 |
| 可解释推荐是否被接受 | 推荐理由认可、纠正、不想被推荐、屏蔽与接受交流，不能只看点击 |
| 关注是否形成持续价值 | 同一创作者被多周回访、内容被主动收藏/分享、用户是否愿意继续看到，而非只看粉丝数 |
| 创作者是否帮助生活理念落地 | 不同阶段用户是否觉得被接纳、是否找到适合自己的运动内容；不把医疗效果当内容指标 |
| 社区能否兼顾同伴与 KOL | 稳定练友、固定圈复访和创作者回访一起看，避免大号曝光增长却无人获得回应 |

## 7. 验收场景

- 两人计划高度相似但目标背景未知：只说计划结构接近，不宣称身体一样。
- 同一套默认模板匹配到大量用户：降置信并核对区分度，不展示虚假的精确百分比。
- 不同动作名属于相同模式：可以保留共同点；不同目标只有一个动作重合：不判高度相似。
- 没计划、未知经验或计划已弃用：按明确选择降级推荐，不把未知值当匹配成功。
- 计划更新：更新新候选，已关注与已有朋友不自动删除。
- 用户关闭计划推荐：停止相关发现及缓存使用，不删除其主动关注。
- 用户有伤病但没有主动公开：候选理由、人数与标签不泄露或推断病情。
- 第一天关注公开创作者：可以看到公开内容，不因此获得私聊或私人计划。
- 私密账号移除粉丝/屏蔽：后续内容和媒体访问权限及时失效。
- 散步用户关注力量创作者：允许；不要求计划相似，不贬低其运动形式。
- 高等级普通用户或大粉丝账号：没有自动专业认证或圈子管理权限。
- 同路用户想照抄对方剂量：社区不自动应用，仍走本人计划与规则层。

本文件记录设计与现状核对；首批实现见[实施记录](COMMUNITY-IMPLEMENTATION.md)。推荐基线的关系效果、权重与置信门槛仍需实际数据验证。

### 内容价值补充验收

- 用户只发一张自己喜欢的生活或运动照片，没有附训练数据：可以按正常内容规则发布和被推荐，不要求补一段教学。
- 用户因为照片好看而关注，或因为经历有共鸣而关注：两种动机均成立，不强制解释或绑定某种价值观标签。
- 发现与关注流兼容审美、经验、信息、情绪和生活向往；内容效果不只用是否促成训练或知识收藏评价。
