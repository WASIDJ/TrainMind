# 设计参考与首页/记录页重做（2026-11-11）

用户给了一个参考仓库 [justkawal/UI](https://github.com/justkawal/UI)（Flutter 重绘的
Dribbble 设计稿合集），要求学习。看了其中 courses / wellbeing / databest /
finances / meditate / social_chats 六组稿。

## 参考稿的共性（不是配色，是结构）

1. **每屏只有一个主角**：wellbeing 一屏只讲一句话 + 一张占半屏的插画；
   databest 是"左卡图形 + 右卡 500+"两栏不等宽，形成呼应。
2. **列表行的每个字段只出现一次**：courses 的行是「缩略图 / 日期 / 标题 / 时长」
   四栏，每栏字号不同，靠字重和颜色分主次，而不是靠重复文字。
3. **强调色只给按钮和关键数字**：wellbeing、databest 全程一个强调色，
   绝不用在装饰上。
4. **留白是主动设计出来的**：meditate 一屏 80% 是空的，仍然成立。

对照 TrainMind 的问题：卡片全部同宽同高（视觉重量平均 → 没有重点）、
同一个词在一行里说两遍、强调色同时出现在按钮/进度/路径/序号/图标上。

## 这一版改了什么

### 记录页
- 头部从「累计训练 12 / 累计时长 300 min」两个同权重数字，改成 **本周场次当主角**
  （44px 大字），本月与累计降为一行小字。原来的两个数字回答的是"这辈子练了多少"，
  不是打开这一页想知道的"这周怎么样"。
- 记录卡片从「日期·课名 一行 + 副行塞分钟/动作/百分比」改成三栏：
  **日期大字 / 课名+摘要 / 完成度环**。满进度（100%）的环是灰的——
  六场都 100% 时六个黄环只会变成噪音，强调色留给没练完的行。
- 肌群账本从 8 行（每行「● 腿  本周还没练」+「腿：还没有记录 · 近7天 0 组」，
  同一词说两遍）收成 **4 行**：有数字的排前面（部位 / 状态 / 组数三栏），
  没记录的 5 个肌群合成最后一行。配套把 `src/muscles.ts` 里每句文案开头的
  `${meta.label}：` 去掉——部位名已经在独立一列了。

### 首页
- 「看看下一场练什么」从 4 个气泡之一提升为**唯一实心主行动**。
  原来它和「安排今天的训练」并列，两者其实是同一件事。
- 建议气泡从两行两列（占小半屏）改成**一行横向滑动**，样式退成辅助入口。
- 欢迎块在可用空间里垂直居中，底部那片纯黑死白分摊到上下两侧。
